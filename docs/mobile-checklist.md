# Mobile checklist (10 minutes, founder's phone)

No code substitutes for a real device. Run once on iOS Safari and once
on Android Chrome, on the live deploy, signed out AND as owner. Check
each box or file the failure as a ticket — do not "fix" by shrinking
desktop.

## Widget panel (guest, demo1 site)

- [ ] Chat button visible, tappable, not overlapping site UI.
- [ ] Panel opens full-width; greeting + suggestions readable, no sideways scroll.
- [ ] Send a message: keyboard opens without hiding the input; reply streams.
- [ ] Quote card: total prominent, dates wrap cleanly, no overflow.
- [ ] Bengali reply: script renders (no tofu boxes), wraps cleanly.
- [ ] Rotate to landscape: panel still usable, input reachable.

## Staff board (/staff, owner login)

- [ ] Triage list readable; filters tappable (≥44px targets).
- [ ] Open a transcript: no sideways scroll; notes field usable with keyboard.
- [ ] Assign + resolve actions work by touch.

## Settings + setup (owner login)

- [ ] Section nav scrolls horizontally; tapping a link jumps to the room.
- [ ] Sticky nav doesn't cover room headings when jumping (scroll margin).
- [ ] /setup wizard: snippet block scrolls horizontally inside the card;
      buttons tappable; mint-once token readable without zoom.
- [ ] Landing strip (`/`): name + badge + link line wrap cleanly.
